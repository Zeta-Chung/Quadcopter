本项目用于四轴飞行器设计开发

设备：NUCLEO-F401RE

时钟源：HSE，8MHz

# 引脚对应
PA0 - TIM2-CH1 PWM输出引脚  

PA1 - TIM2-CH2 PWM输出引脚  

PA2 - TIM2-CH3 PWM输出引脚  

PA3 - TIM2-CH4 PWM输出引脚

PA8 - TIM1-CH1 接收机捕获引脚（临时）

PA9 - 蓝牙USART的Tx引脚  

PA10 - 蓝牙USART的Rx引脚  





PB6 - OLED软I2C的SDA引脚  

PB7 - OLED软I2C的SCL引脚  

PB8 - GY-86软I2C的SCL引脚  

PB9 - GY-86软I2C的SDA引脚
